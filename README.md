# Fantasy DH — Vue

Vue 3 + TypeScript port of the original Angular [Fantasy DH](https://github.com/paultrial/fantasy) application.

## Features

- 2026 and 2025 rider datasets
- $1.5M team builder with four men's and two women's slots
- Rider filters, sorting, form charts, injury and Instagram indicators
- Saved current team and team history in local storage
- Exact best-team calculation for each completed round
- Predicted next best team calculation

## Development

```sh
npm install
npm run dev
```

Open the URL printed by Vite. Use `npm run build` for a production build and `npm run lint` for static checks.
